# 风过旷野 · 海风群岛 · 烟雨江南

三个可切换的程序化风景网页，采用提前绘制的有限地图持续循环。草原与海岸跟随飞机，江南跟随乌篷船漫游。

- [风过旷野：草原与河流](https://ablessa.github.io/-wind-over-meadow/)
- [海风群岛：岛屿与浅滩](https://ablessa.github.io/-wind-over-meadow/coast.html)
- [烟雨江南：随舟经过水巷、古塔与石桥](https://ablessa.github.io/-wind-over-meadow/jiangnan.html)

草原与海岸保留 24 秒的 S 形飞行与快慢变化；江南采用 72 秒的随舟旅程，主船前进时，其他小船慢行或靠岸。完整运动周期为 360 秒。

江南包含 23 栋普通房屋、两座古塔、石拱桥和石梁桥，以及草丛、垂柳与竹林。民居、店铺、木窗长楼和围合院落各有不同形态，部分房屋由河边柱脚支撑。桥上、岸边和房屋附近共有 18 位行人。

下方按钮可暂停、调整播速、重新开始与全屏观看。推荐电脑浏览器；系统开启“减少动态效果”时，点击“继续”开始播放。

每个 HTML 文件均自带程序和样式，没有外部图片、模型、字体或第三方脚本依赖。下载三个 HTML 到同一文件夹，可离线观看并切换场景。

GitHub Pages 从 main 分支根目录发布。实际网络可达性以访问者所在网络为准。
