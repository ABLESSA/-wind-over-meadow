# 风过旷野 · 海风群岛

两个可切换的程序化飞行风景网页：像素植被、飞机 S 形滑翔、云层穿越与云影，采用提前绘制的有限地图持续循环。

- [风过旷野：草原与河流](https://ablessa.github.io/-wind-over-meadow/)
- [海风群岛：岛屿与浅滩](https://ablessa.github.io/-wind-over-meadow/coast.html)

下方按钮可暂停、调整播速、重新开始与全屏观看。推荐电脑浏览器；系统开启“减少动态效果”时，点击“继续”开始播放。

每个 HTML 文件均自带程序和样式，没有外部图片、模型、字体或第三方脚本依赖。下载两个 HTML 到同一文件夹，可离线观看并切换场景。

GitHub Pages 从 main 分支根目录发布。实际网络可达性以访问者所在网络为准。
